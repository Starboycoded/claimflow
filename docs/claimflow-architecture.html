Four Rs Fraud Detection Framework
Developed during HackerRank Orchestrate June 2026 — adapted for Qwen Cloud.
R1
Recognize
Separate claim text from actual visible findings in images
R2
Reject
Flag claims where images show a different object or part than claimed
R3
Reveal
Detect image manipulation, text instructions in photos, non-original images
R4
Route
Check user history — flag repeat claimants, prior fraud flags, suspicious patterns
